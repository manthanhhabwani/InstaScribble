# InstaScribble

InstaScribble is a lightweight, privacy-first note-taking web application built with HTML, CSS, and JavaScript.

Unlike cloud-based note apps, your notes remain stored locally in your browser. No account, no sign-up, and no server required.

Simply open the app, write your thoughts, and access them whenever you need them.

## Why InstaScribble?

- ⚡ Lightweight and fast
- 🔒 Privacy-first
- 💻 Works entirely in your browser
- 📱 Responsive for desktop and mobile
- 📝 Simple, distraction-free experience
