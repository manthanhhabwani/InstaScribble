# InstaScribble Requirements

## Goal
Build a responsive note-taking application using HTML, CSS, and JavaScript.

## Version 1.0 Features
- Create notes
- Edit notes
- Delete notes
- Search notes
- Grid/List view
- Sort notes
- Local Storage

## Future Features

- Favorites
- Archive

- Dark mode
- Cloud sync
